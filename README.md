# Business Management System — демо-материалы

Выдержки из закрытого коммерческого проекта: система учёта для малого бизнеса с доставкой (заказы, склад, финансы, CRM, логистика, Telegram-бот). Исходный код закрыт, поэтому здесь только то, что можно показать: фрагмент кода, прогон тестов, структура миграций и список эндпоинтов API. Данные клиентов, названия товаров и суммы в материалах отсутствуют или замаскированы.

## Стек

Python 3.12 · FastAPI · SQLAlchemy 2 (async) · Alembic · PostgreSQL · Redis · aiogram 3 · Telethon · Next.js / React / Tailwind

## Архитектурная идея фрагмента

Синхронизация разделена на два слоя. Слой чистой логики не импортирует telethon и работает только с `IncomingTgMessage`, поэтому покрыт юнит-тестами на in-memory БД. Тонкая обёртка над telethon переводит его объекты в этот dataclass. Дедупликация по паре `(customer_id, telegram_message_id)` делает повторную синхронизацию истории безопасной.
